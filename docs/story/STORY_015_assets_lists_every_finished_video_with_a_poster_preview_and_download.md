## Acceptance Criteria

- [x] `/assets` lists history entries with `status: done`, newest first, as tiles: poster from `/api/jobs/:id/poster` (falls back to the video glyph), file name `<title>.mp4`, hover reveals **Preview** and the kebab; keyboard users reach both.
- [x] Tabs: **From Agent** active; From You and Star rendered inert. Filter chips: **All** and **Videos** show the tiles (identical here), the others show the empty state "No <kind> yet"; the search field filters by title (case-insensitive) as you type.
- [x] Empty state (no finished job): "No assets yet", "Files generated by AI and uploaded by you will appear here", **+ New task** → `/`.
- [x] Preview modal: title bar with the file name and three icon buttons — **Download** (`download` link to the result), **Open task** (`/task/:id`, replaces the reference's open-in-new), **Close**; a native `<video controls>` with the result `src` and poster; Escape and the scrim close it; focus returns to the tile.
- [x] Kebab menu: **Open task**, **Download**, **Delete from history** (removes the entry via `DELETE /api/history/:id` after a confirm; the file on the Spark is untouched — Departures).
- [x] Narrow (390): two-column tiles, the modal full width with controls ≥ 44 px.

## Departures from the reference

- Only videos exist locally; the other filter chips and the From You / Star tabs are rendered inert.
- "Open in new" becomes "Open task": the result already lives in the task page.
- Favourites, drive categories and the poster's "front page screenshot" are not implemented; the poster is the adapter's first frame.
- Delete removes the history entry only; ComfyUI's output file stays on disk (the owner decides about disk by hand).

## Technical Notes

- Pure filtering/search in `lib/assets-filter.ts`; the page is a client component over `GET /api/history`.
- The modal is a `<dialog>` element for native focus trapping and Escape.

## Testing Plan

- **Unit** — `lib/assets-filter.test.ts`: only done entries; search is case-insensitive and matches the title; chips other than All/Videos yield empty. `components/assets/AssetsPage.test.tsx`: empty state; tiles render with poster src; the modal opens with the right video src and closes on Escape.
- **Integration** — covered by STORY_014's history routes; `DELETE /api/history/:id` is asserted there too.
- **E2E** — `e2e/assets.spec.ts` (desktop + narrow): with no jobs, the empty state and its New task link; after one `done-after-1-poll` job created through the app's route, the tile appears, Preview opens the modal and `expectPlayable(video, "/api/jobs/<id>/result")`, Download yields a file the size of the fixture, Open task lands on `/task/<id>`, Delete from history removes the tile. Regression: `task.spec.ts`, `shell.spec.ts`.
